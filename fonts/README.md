# Catàleg de fonts
La carpeta `fonts/` conserva les referències que poden justificar afirmacions curriculars o normatives.
## Estructura
- `README.md`: explica el procediment del catàleg.
- `registre-fonts.md`: índex de treball amb les fonts i el seu estat.
En una ampliació posterior, el catàleg podrà incorporar les carpetes `normativa/`, per a les fitxes de legislació estatal i valenciana, i `bibliografia/`, per a les obres de consulta que no substituïxen la normativa.
Aquestes carpetes encara no es creen en aquesta unitat.
## Procediment
Consulta primer el registre i després obri el document oficial concret.
Anota l’organisme, el títol, l’URL, l’apartat, l’etapa, la data de
consulta i l’estat de la font.
Estats permesos: `VERIFICADA`, `PENDENT` i `NO APLICABLE`.
