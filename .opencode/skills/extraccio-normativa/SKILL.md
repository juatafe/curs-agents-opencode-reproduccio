# Procediment d’extracció normativa

## 1. Reuneix el context
Identifica l’etapa, família o modalitat, cicle o curs i mòdul o matèria.

Abans de redactar o de fer afirmacions sobre currículum, avaluació o normativa,
consulta primer l’índex de `fonts/` i les referències pertinents. Si una font no
hi apareix, busca-la només en un lloc oficial si tens una eina de consulta
configurada; verifica l’etapa i el curs abans de proposar afegir-la al catàleg.
Anota organisme, títol, enllaç oficial, etapa o ensenyament, curs acadèmic si
escau, data de consulta i estat de vigència. Si no pots verificar-la, marca-la
com a pendent i pregunta. No presentes un PDF antic com si fora vigent.

Si falten dades importants, pregunta. No inventes dades de la normativa.

## 2. Extreu sense interpretar
Registra text, apartat, URL, data de consulta i estat de vigència. Separa el
text extret de qualsevol resum o proposta i marca `PENDENT` el que no pugues
comprovar.

## 3. Presenta l’evidència
Deixa el resultat en `sortides/esborranys/` perquè `integrador-sabers` i
`generador-graelles` el puguen reutilitzar. No completes buits amb coneixement
general.

## 4. Presenta el resultat
Indica què està verificat, què és una interpretació i què queda pendent.
